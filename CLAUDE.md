# Working rules for this repo

- Ask questions with the AskUserQuestion tool: multiple choice, recommended
  option first and labelled "(Recommended)". No open-ended questions in chat.
- Never add hardware (bolts, rods, bearings, springs, magnets...) to a design
  without the owner's explicit confirmation.
- Never download or use an external skill without the owner's confirmation.
- Layout: one folder per model under `projects/`; shared OpenSCAD modules,
  guideline skills and tools under `common/` (see README.md).
